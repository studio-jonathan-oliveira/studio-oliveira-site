#### Détails par typologie (citations directes Jonathan)

**Micro-urbain** (l. 101-113)
- **Exemples** : Terrasses, rooftops, patios intérieurs/extérieurs
- **Identité** : « L'espace extérieur se définit comme **une pièce à part entière de l'habitation**, en total prolongement de la pièce adjacente »
- **Complexité principale** : support ouvrage (étude structure portante obligatoire), orientation/ombre/humidité, enclavement spatial, faible disponibilité au sol

**Cœur urbain** (l. 117-135)
- **Exemples** : Jardins confinés en centre-ville, cours patrimoniales, maisons de caractère
- **Phrase signature** : « Très technique, très risqué, très précieux et très stratégique »
- **Complexité** : ABF + PLU, réseaux souterrains, coefficient pleine terre, calculs portance, gestion eaux pluviales, protection arbres existants, **responsabilité décennale engagée**

**Frange urbaine** (l. 139-159)
- **Exemples** : Pavillons, maisons d'architecte, gîtes, bâtis industriels reconvertis
- **Phrase signature** : « Un territoire instable entre nature et ville »
- **Complexité** : sols rarement naturels, hydrologie instable, pression climatique, PLU, trames vertes, zones inondables, **ouvrages de soutènement** (responsabilité concepteur engagée sur ouvrages techniques)

**Domaines & Caractère** (l. 163-181)
- **Exemples** : Châteaux, manoirs, granges rénovées, domaines familiaux
- **Phrase signature** : « Un dialogue entre une architecture ancienne, un sol fatigué, un paysage réel et une mémoire invisible »
- **Complexité** : surface massive, exigence patrimoniale/architecturale au plus haut, segmentation obligatoire de la conception, plannings longs, rémunération échelonnée

### 3.4 Les 3 phases de prestation

#### Phase 1 — Étude préliminaire (l. 5-14, 185-214)
- **Objectif** : contextualisation, diagnostic, analyse site, faisabilité, estimation
- **Paiement** : comptant à signature devis
- **Livrables** : note présentation + plan situation + photographies site + réglementation/urbanisme + programme + zonage/esquisse + plan masse préliminaire + schémas ambiances + moodboard + fourchette budgétaire + synthèse faisabilité + RDV autorités (ABF, mairie, UDAP)

#### Phase 2 — Étude projet (l. 16-27, 218-258)
- **Objectif** : conception approfondie, DCE, consultation entreprises, pilotage
- **Paiement** : comptant à signature devis
- **Livrables** : plan masse projet + coupes/élévations + schéma circulations + plan nivellement + gestion eaux pluviales + plans plantations + palettes végétales + palettes matériaux + perspectives/rendus + DCE (terrassement, maçonnerie, sols, bois/métal, arrosage, éclairage, plantations) + détails techniques (murs, terrasses, bordures, ouvrages spéciaux) + budget détaillé par lot + dossier réalisation + planning chantier + documents validation matériaux

#### Phase 3 — Suivi de chantier (l. 260-266)
- **Objectif** : coordination artisans, pilotage, respect intentions projet
- **Tarification** : % des travaux estimés (cf. tableau 3.2)
- **Livrables** : comptes-rendus chantier + suivi avancement + validation ouvrages + suivi financier + réception fins travaux

### 3.5 Le parcours commercial — 3 étapes exactes

**Source** : PDF lignes 325-405

#### Étape 1 — Appel découverte (15-25 min)
- **Qualification** : localisation, typologie, surface, budget, maturité projet
- **Explication** : méthode étude, filtre des projets non-alignés
- **Sortie** : préparation dossier projet par client (cadastre, plans maison + propriété, images référence) + envoi **document « approche du process projet »**

#### Étape 2 — RDV bureau ou visio (1h45-2h)
Décomposition précise (l. 351-394) :
- **10 min** — Accueil + café + observation dynamique client
- **— min** — Récit client : mode de vie, attentes, frustrations, rêves (écoute + reformulation)
- **30 min** — Immersion co-construction : images référence, tri, lecture sensible — **faire participer les clients**
- **20 min** — Lecture experte : contraintes site, potentiels, cohérence projet/budget/usages — **prise du lead**
- **15-20 min** — Présentation étude : typologie, apport, livrables, déroulé temporel, prix
- **Sortie** : validation étude, délai acceptation (min 72h, max 1 semaine), RDV validation à distance

#### Étape 3 — Validation distance (15 min)
- **Objectifs** : lever dernière hésitation, répondre question, fermer vente
- **Action finale** : envoi devis signature (si clients loin) OU signature devis au studio (si locaux)

### 3.6 Collaborateurs pros — process

**Source** : PDF lignes 407-470

- **Phase 1 (pré-étude)** : fourchette estimative budgétaire, 1-2 RDV, collaborateur conscient temps non rémunéré + mise en concurrence
- **Phase 2 (projet)** : devis précis par lot, délai création **3 semaines max**
- **Phase 3 (chantier)** : réunion démarrage (site + téléphonique pré-démarrage 1 semaine avant + site jour 1) + réunions régulières avancement

3. **Easings cohérents** : `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo) pour reveals / `cubic-bezier(0.65, 0, 0.35, 1)` pour CTA

5. **1 CTA primaire par section**, pas de répétition intra-section
6. **Max 3 hiérarchies typographiques** : hero / H2 / body
7. **Animations = narration**, pas décoration
